# AI Companion

毎日のジャーナルを、AIとの協力関係に変える Obsidian プラグイン —
ウェルネスコーチのようなものではなく、実用的で等身大のものです。

あなたは今まで通りジャーナルを書き続け、今まで通りスマートフォンからリンクを共有します。プラグインはその両方を読み取り、具体的なアドバイスで応答し、リンクを日々のブリーフィングとして要約し、あなたがどのような人物であるかの全体像を少しずつ構築していくため、時間が経つにつれてより的確な支援が得られるようになります。

## 機能

**ジャーナルフィードバック** — あなたが書いたものを読み、話題に応じた声で回答します：
🫂 親友として、🎒 先生として、🔧 エンジニアとして。各回答はその声の絵文字と名前で始まるため、3つすべてが含まれる日でも、1つの長いテキストの塊ではなく3つの返信として読めます。どの声が何に適用されるかは設定の編集可能なテーブルであり、それぞれの声の絵文字、名前、指示も同様に編集可能です。

**ニュース要約** — スマートフォンからThreads、X、Facebookの投稿をvaultに共有すると、あとはプラグインが行います。共有の見出しの下にリンクをリストし、ソース、要点、なぜ重要なのか、という3つの固定要素で書き出します。リサーチ機能が有効な場合、タイトルから推測するのではなく、各ページを取得して実際に何が書かれているかを要約します。人は仕事で使うため、自分の作品で試すため、家族の誰かのため、あるいは単に良かったからという理由で物事を保存します。そのため、3行目ではそれを使って何ができるかを述べており、評価することは決してありません。

**完全なレポート** — ある項目が数行以上の価値がある場合、AIはそれにマークを付け、その日のフォルダに独自のノートを書きます — それは何か、どうやってやるか、何に注意すべきか — その方法をそのまま引用して、ソースを再び開かなくても使えるようにします。要約のエントリはそこにリンクされます。1回の実行ごとの上限があり、オフに切り替えることも可能です。

**事実テーブル** — AIはあなたに関する持続的な事実（人、プロジェクト、目標、繰り返し発生する問題）を通常の編集可能なノートに蓄積します。他のすべての機能は、回答する前にこれを読み取ります。事実は*現在の*状態として述べられ、物事が変化するにつれて書き換えられるため、ファイルは変更履歴のように肥大化するのではなく、数ヶ月後でも読みやすい状態を保ちます。

## 1日の流れ

1. 日中、スマートフォンからランディングフォルダにリンクを共有します。
2. ジャーナルを書きます — 自分で書くのはジャーナルセクションのみで、残りは自動的に入力されます。
3. **Generate Digest**を実行します。共有した内容は共有の見出しの下に、要約は要約の見出しの下に表示され、共有ノートはアーカイブに移動します。
4. 書いたことへの返答が欲しい時に**Generate Journal Feedback**を実行します。

または、スケジュールを設定して、ステップ3と4を自動的に行わせることもできます。

## デイリーノートのレイアウト

1番目と3番目のセクションはあなたが作成し、2番目と4番目はAIが書きます。

```markdown
## ジャーナル
- 今日やったこと

## AIフィードバック
- (AIがここに書きます、タイムスタンプ付き)

## 今日の共有
- (AIがここに共有したリンクをリストします)

## AIまとめ
- (AIがここに書きます、タイムスタンプ付き)
```

見出しはObsidianの言語設定に従うため、中国語インターフェースでは`## 日誌`、`## AI回饋`などのように書き込まれます。ある言語の元で書かれたノートは、別の言語でも機能し続けます。マッチングはすべてのロケールの見出しを認識し、既存のセクションは書き換えられることなく、既存の見出しをそのまま保持します。

セクションは見出しによって見つけられるため、ファイル内の順序は関係ありません。コマンドを再実行すると、以前のものを置き換えるのではなく、タイムスタンプ付きの新しいブロックが追加されるため、1日に複数回実行した分が蓄積されていきます。これら4つの見出しの外側にあるものには一切触れません。

## フォルダレイアウト

```
ai-companion/
  journal/              毎日のノート。日ごとにレポート用の独自のフォルダが作成される場合があります。
  news/
    landing/            ← スマートフォンからこのフォルダに共有します
    archived/           処理された共有はここに移動されます
  memory/
    facts.md            AIがあなたについて知っていること — 自由に編集してください
    _log.md             いつ更新されたかの追記のみの記録
```

すべてのフォルダは設定で構成可能です。これらはプラグインが読み込まれる時に作成されるため、モバイルの共有シートで探そうとする前にランディングフォルダは存在しています。

## インストール

デスクトップでObsidian 1.5.0以降が必要です。

1. 最新のリリースから`main.js`、`manifest.json`、および`styles.css`をダウンロードします。
2. これらを`<vault>/.obsidian/plugins/ai-companion/`に配置します。
3. 設定 → コミュニティプラグインで**AI Companion**を有効にします。
4. 設定 → AI CompanionでAIのCLIパスを設定します。

### CLIのセットアップ

プラグインはpromptをローカルのAIのCLIのstdinにパイプし、その標準出力を読み取るため、コマンドは非対話的に実行される必要があります。Claude Codeの場合：

ドロップダウンからCLIを選択すると、その非対話型フラグが自動的に適用されます。実行可能ファイルが`PATH`上にない場合にのみパスを設定してください。

| CLI | ステータス |
| --- | --- |
| Claude Code | 検証済み。promptはstdinで送信されます |
| Antigravity (`agy`) | 検証済み。promptは引数として渡されます |
| Codex (ChatGPT) | 提供されていますが未テストです — 結果を報告してください |

コマンドが出力なしと報告した場合、CLIは対話型セッションを求めていた可能性が高いです。Extra arguments(追加引数)のフラグを確認してください。

### ソースからのビルド

```bash
npm install
npm run build
```

## コマンド

これらはすべてコマンドパレットと、リボンアイコンの裏にあるメニューにあります。

| コマンド | 機能 |
| --- | --- |
| New Journal Note | テンプレートから今日のノートを作成して開きます |
| Generate Journal Feedback | その日のエントリに、各部分が求める声で回答します |
| Generate Digest | 共有した内容をリストし、それぞれについて書き出します |
| Accumulate Facts | その日のエントリから事実テーブルを更新します |
| Open Fact Table | 読んだり修正したりするために`facts.md`を開きます |
| Archive Processed Shares | 残っている処理済みの共有を一掃します |

ジャーナルノートに書き込むコマンドは、ジャーナル以外のノートが開いている間は無効になるため、意図せずファイルに変更を加えることは決してありません。

## 設定

- **AI** — CLI (Claude Code、Antigravity、Codex)を選択すると、必要なフラグが入力されます。またはCustomを選択します。加えてパス、追加引数、モデル、タイムアウト。
- **Voices** — 状況 → 声のテーブルと各声の指示。すべての組み込みエントリは個別にリセット可能です。独自の状況と声を追加してください。
- **Journal** — フォルダ、日付フォーマット、テンプレートパス（`{{date}}`および`{{time}}`をサポート）。カスタムテンプレートは4つの見出しを保持する必要があります。これらはAIがどこに書くべきかを見つけるためのものです。
- **News** — ランディングおよびアーカイブフォルダ、リサーチの切り替え、アーカイブの保持日数（0はすべてを保持）。
- **Schedule** — 手動（デフォルト）、開いた時、またはN時間ごと。スケジュールされたパスで要約、フィードバック、またはその両方を実行するかどうかの個別の切り替え機能があります。
- **Facts** — フォルダ、および有効にするトグル（デフォルトではオフ）。
- **Appearance** — プラグイン独自のセクション用のオプションのスタイル（カード、クワイエット、マガジン）。デフォルトではオフで、ジャーナルノートに限定されます。スタイルは閲覧ビューで適用されます。すべての値はObsidianのCSS変数から来ているため、あなたのテーマが引き続き優先されます。

### スケジューリング

スケジュールされた実行はObsidianが開いている間にのみ行われます — CLIを活用したプラグインにはバックグラウンドプロセスがなく、実行機会を逃した場合は、追いつくのではなく次の周期でピックアップされます。

要約はスケジュールに合っています。なぜなら、各実行で新しく届いた共有を処理するからです。スケジュールされた実行では、ジャーナルフィードバックはデフォルトでオフになっています。パスごとに新しいブロックが追加されるため、1日に6回実行すると、セクションがほぼ同じアドバイスで埋め尽くされてしまうためです。

## プライバシーと安全性

何かを有効にする前にこれをお読みください。

- **あなたのジャーナルはAIプロバイダーに送信されます。** プラグインはローカルのAI CLIを生成し、ジャーナルのテキストをそこにパイプします。そのCLIがさらに何を誰に送信するかは、このプラグインではなくそのツールによって管理されます。ジャーナルには健康上の詳細や家族の問題が含まれるため、慎重に決定してください。
- **AIはvaultに直接書き込みます。** 確認のステップはありません。上記にリストされたセクションにのみ書き込みますが、尋ねることなく行います。
- **出所は保持されます。** `memory/_log.md`は追記のみであり、各事実の更新がどのジャーナルの日から来たのかを記録するため、あなたが書いたこととAIが推論したことを分けることができます。
- **事実テーブルはあなたが編集するものです。** もしAIが間違ったことを記録した場合は、それを開いて修正してください。次回の実行ではあなたが修正したバージョンが読み込まれます。AIは毎回ファイル全体を書き直すため、ジャーナル内で裏付けのない行は生き残らない可能性があることに注意してください。
- **スケジューリングはデフォルトで手動です。** vaultに書き込む無人実行は、デフォルトではなく意図的な決定であるべきです。
- **アーカイブの削除はオプトイン**であり、システムのゴミ箱を使用するため、復元可能です。
- **デスクトップのみ。** CLIを生成するにはNodeが必要なため、モバイルでは実行できません。スマートフォンからvault*へ*の共有は問題なく機能します — それは単にObsidian Syncのことです。

## 国際化

インターフェースはObsidian独自の言語設定に従い、21の言語で提供されています：アラビア語、ドイツ語、英語、スペイン語、ペルシア語、フランス語、インドネシア語、イタリア語、日本語、韓国語、オランダ語、ポーランド語、ポルトガル語、ポルトガル語（ブラジル）、ロシア語、タイ語、トルコ語、ウクライナ語、ベトナム語、中国語（簡体字）、および中国語（繁体字）。

翻訳は`src/i18n/locales/`にあります。各ロケールは英語に対して型付けされているため、キーが欠落している場合は暗黙のフォールバックではなくコンパイルエラーになります。
