# AI Companion

【[English](../README.md) | [繁體中文](README.zh-TW.md) | 简体中文】

一个 Obsidian 插件，让 AI 真正参与你的日志 —— 务实、贴近生活，不是心灵导师。

你照原本的方式写日志，照原本的方式用手机分享链接。插件会读这两者，用具体的话回应你，
把链接整理成当天的简报，并逐步累积它对你的认识，让建议愈来愈贴合你的状况。

## 功能

**日志反馈** — 读你写的东西，用该用的口吻回应：🫂 吵架时是心灵导师、🎒 孩子的事是学校老师、
🔧 程式问题是技术顾问。每则回应开头会标上该角色的表情符号和名称，所以一天里混杂的三件事
读起来就是三则回应，而不是一整面文字。什么情境用什么角色是设定里一张可编辑的表，
每个角色的表情符号、名称、指示也都能改。

**新知汇总** — 用手机把 Threads、X、Facebook 的贴文分享进 vault，其余插件处理：
它会把链接列进转贴区，再依内容写成摘要。开启研究模式时会实际抓取每个页面，
依它真正写了什么来摘要，而不是从标题猜。人存东西的理由很多 —— 工作要用、想自己试试、
家人可能用得上，或单纯觉得好 —— 所以摘要只讲你能拿它做什么，不会评价它重不重要。

**完整报告** — 当某一项值得展开时，AI 会在当天的文件夹另外写一篇笔记：这是什么、怎么做、
要注意什么，并把方法逐字引用下来，让你不用回头开原文就能直接用。汇总那一条会连过去。
每次执行有数量上限，也可以关闭。

**事实表** — AI 会把关于你的长期事实（人、专案、目标、反复出现的问题）累积在一则
一般的、可编辑的笔记里，其他功能回答前都会先读它。事实是以**现况**陈述并随变化改写，
所以写了几个月之后仍然好读，不会长成一份流水帐。

## 一天怎么运作

1. 白天用手机把链接分享到落地文件夹。
2. 写你的日志 —— 只要写“日志”那一区，其余会帮你补上。
3. 执行**产生新知汇总**。你的分享会出现在转贴区、摘要出现在汇总区，分享档则移到归档。
4. 想要回应时，执行**产生日志反馈**。

或者设定排程，让第 3、4 步自己发生。

## 每日笔记版面

第一区和第三区是你的，第二区和第四区由 AI 写。

```markdown
## 日志
- 今天做了什么

## AI反馈
- （AI 写在这，附时间戳）

## 今日社群转贴
- （AI 把你分享的链接列在这）

## AI整理社群新知
- （AI 写在这，附时间戳）
```

标题会跟著 Obsidian 的介面语言走，所以英文介面写的是 `## Journal`、`## AI Feedback`。
用某个语言写的笔记换到另一个语言仍然可用：比对时认得所有语言的标题，而既有区块会保留
它原本的标题，不会被改写。

区块是靠标题定位的，所以它们在文件里的顺序不影响运作。重跑指令会附加一段新的、
带时间戳的内容，而不是覆盖先前的，所以一天跑好几次会累积下来。四个标题以外的东西
永远不会被动到。

## 文件夹结构

```
ai-companion/
  journal/              每日笔记；每天可以有自己的同名文件夹放报告
  news/
    landing/            ← 手机分享请选这个文件夹
    archived/           处理完的分享会搬到这
  memory/
    facts.md            AI 对你的了解 —— 可自由编辑
    _log.md             唯读附加的更新纪录
```

每个文件夹都可以在设定里改。插件载入时会自动建立，所以你在手机分享时就已经选得到
落地文件夹了。

## 安装

需要桌面版 Obsidian 1.5.0 以上。

1. 从最新的 release 下载 `main.js`、`manifest.json`、`styles.css`。
2. 放进 `<vault>/.obsidian/plugins/ai-companion/`。
3. 在“设定 → 第三方插件”启用 **AI Companion**。
4. 到“设定 → AI Companion”设定你的 AI CLI。

### 设定 CLI

插件会把 prompt 交给本机的 AI CLI 并读取它的输出，所以那个指令必须能非互动执行。
从下拉选单选好你的 CLI，需要的参数就会自动带入 —— **路径通常留空即可**，
插件会去常见的安装位置找。只有当它找不到时才需要自己填。

| CLI | 状态 |
| --- | --- |
| Claude Code | 已验证；prompt 走 stdin，研究模式可用 |
| Antigravity (`agy`) | 已验证；prompt 当引数传入 |
| Codex (ChatGPT) | 有提供但未实测 —— 欢迎回报结果 |

若指令回报没有输出，多半是那个 CLI 想进入互动模式，请检查“额外参数”栏位。

**Antigravity 的研究模式有限制**：agy 在非互动模式下无法核准网路权限，要开启研究模式
需要在它的 `settings.json` 加上 allow-rule。不需要抓网页的功能则完全正常。

### 从原始码建置

```bash
npm install
npm run build
```

## 指令

以下都在指令面板里，也在左侧功能区图示的选单中。日志笔记的右键选单则提供针对**那一天**
重跑的选项。

| 指令 | 做什么 |
| --- | --- |
| 建立今日日志 | 依模板建立今天的笔记并开启 |
| 产生日志反馈 | 用该用的口吻回应当天的日志 |
| 产生新知汇总 | 列出你的分享并逐则写成摘要 |
| 累积事实表 | 从当天的日志更新事实表 |
| 开启事实表 | 打开 `facts.md` 阅读或修正 |
| 归档已处理的转贴 | 清掉中断执行留下的残留 |

会写入日志笔记的指令，在你打开非日志笔记时会停用，所以它们不会动到你没打算改的文件。

## 设定

- **AI** — 选你的 CLI（Claude Code、Antigravity、Codex），需要的参数会自动填好；
  或选“自订”。另有路径、额外参数、模型、推理强度、超时时间。
- **日志** — 文件夹、日期格式、模板路径（支援 `{{date}}` 和 `{{time}}`）。
  自订模板必须保留那四个标题，AI 是靠它们定位的。
- **新知** — 落地与归档文件夹、研究模式开关、归档保留天数（0 表示永久保留）。
- **排程** — 手动（预设）、开启时、或每 N 小时，并可分别勾选排程要跑汇总、反馈、或两者。
- **角色** — 情境→角色对应表，以及每个角色的指示。内建项目可个别恢复预设，
  也可以新增自己的情境和角色。
- **外观** — 为插件自己的区块选一个样式（卡片／低调／杂志），预设关闭且只套用于日志笔记。
  样式只在阅读模式生效；所有数值都取自 Obsidian 的 CSS 变数，所以你的主题仍然说了算。

### 关于排程

排程只在 Obsidian 开著时执行 —— 以 CLI 为基础的插件没有背景程序，错过的时段会在
下一次触发时处理，而不会补跑。

新知汇总适合排程，因为每次处理的都是新到的分享。日志反馈在排程中预设关闭：
每次执行都会附加一段新的反馈，一天跑六次会让那一区塞满几乎相同的建议。

## 隐私与安全

启用任何功能前请先读这一段。

- **你的日志会被送到 AI 供应商。** 插件启动本机的 AI CLI 并把日志文字交给它。
  那个 CLI 接下来把资料送去哪、送给谁，是由那个工具决定，不是这个插件。
  日志里有健康状况和家人的事，请审慎选择。
- **AI 会直接写入你的 vault**，没有确认步骤。它只写上面列出的那些区块，但写的时候不会问你。
- **保留溯源纪录。** `memory/_log.md` 是唯读附加的，记录每次事实更新来自哪一天的日志，
  让你能分辨哪些是你写的、哪些是 AI 推论的。
- **事实表是你的，可以自己改。** AI 记错了就打开改掉，下次执行会以你改过的版本为准。
  但要注意 AI 每次都会重写整份文件，所以日志里没有依据的内容不一定会留下来。
- **排程预设为手动。** 无人看管、会写进你 vault 的执行，应该是一个决定，而不是预设值。
- **归档删除需自行开启**，且走系统资源回收站，可以救回来。
- **仅限桌面版。** 启动 CLI 需要 Node，所以无法在手机上执行。但**从手机分享进 vault**
  完全没问题 —— 那是 Obsidian Sync 在做的事。

## 多语言

介面提供 22 种语言，跟随 Obsidian 自己的语言设定：阿拉伯文、德文、英文、西班牙文、
波斯文、法文、印地文、印尼文、义大利文、日文、韩文、荷兰文、波兰文、葡萄牙文、
巴西葡萄牙文、俄文、泰文、土耳其文、乌克兰文、越南文、简体中文、繁体中文。

翻译放在 `src/i18n/locales/`。每个语言都以英文为型别依据，所以少一个 key 会编译失败，
而不是静默退回英文。
