매일 쓰는 일기를 AI와의 협업 관계로 바꿔주는 Obsidian 플러그인입니다. 웰니스 코치 같은 거창한 것이 아닌, 실용적이고 현실적인 크기의 도움을 제공합니다.

평소처럼 일기를 쓰고, 평소처럼 휴대폰에서 링크를 공유하세요. 플러그인이 이 두 가지를 모두 읽고, 구체적인 조언으로 답하며, 링크를 요약하여 일일 브리핑으로 만들어줍니다. 또한 시간이 지날수록 당신이 어떤 사람인지에 대한 그림을 천천히 완성해 나가므로, AI의 도움이 점점 더 개인에게 맞춰지게 됩니다.

## 기능

**일기 피드백** — 당신이 쓴 글을 읽고 주제에 맞는 목소리로 대답합니다: 🫂 다툼에 대해서는 믿을 수 있는 친구가, 🎒 자녀에 대한 일에는 선생님이, 🔧 버그에 대해서는 엔지니어가 되어줍니다. 각 답변은 해당 목소리의 이모지와 이름으로 시작하므로, 세 가지 주제가 있는 날에는 하나의 긴 글이 아니라 세 개의 별도 답장처럼 읽힙니다. 어떤 목소리를 어디에 적용할지는 설정의 편집 가능한 테이블에서 정할 수 있으며, 각 목소리의 이모지, 이름, 지시사항도 마찬가지로 설정 가능합니다.

**뉴스 요약** — 휴대폰에서 Threads, X, 또는 Facebook의 게시물을 vault로 공유하면, 플러그인이 나머지를 알아서 처리합니다: 공유된 링크를 공유 헤딩 아래에 나열한 뒤, 출처, 핵심 내용, 중요한 이유의 세 가지로 정리해서 작성합니다. 리서치 기능이 켜져 있으면 제목만 보고 추측하는 대신 각 페이지를 가져와서 실제로 어떤 내용인지 요약합니다. 사람들은 직장에서 쓰기 위해, 자신의 작업에 적용해 보기 위해, 가족에게 주려고, 또는 단순히 내용이 좋아서 무언가를 저장합니다. 그래서 세 번째 줄은 그것을 어떻게 활용할 수 있는지 알려줄 뿐, 절대 평가하지 않습니다.

**전체 보고서** — 어떤 항목이 두세 줄 이상의 가치가 있다고 판단되면, AI가 이를 표시하고 그날의 폴더에 별도의 노트를 작성합니다 — 무엇인지, 어떻게 하는지, 주의할 점이 무엇인지 — 출처를 다시 열지 않아도 바로 쓸 수 있도록 방법을 그대로 인용합니다. 요약 항목에는 이 노트로 연결되는 링크가 포함됩니다. 실행당 생성 개수가 제한되어 있으며 끌 수도 있습니다.

**사실 테이블** — AI는 당신에 대한 지속적인 사실(사람, 프로젝트, 목표, 반복되는 문제)을 모아 평범하고 편집 가능한 노트에 저장합니다. 다른 모든 기능은 답변하기 전에 이 노트를 읽습니다. 사실은 *현재* 상태 그대로 기술되며 상황이 변하면 다시 쓰이기 때문에, 몇 달이 지나도 변경 로그처럼 길어지지 않고 읽기 쉽게 유지됩니다.

## 하루의 작동 방식

1. 낮 동안 휴대폰에서 착륙 폴더로 링크를 공유합니다.
2. 일기를 쓰세요 — 저널 섹션만 쓰면 됩니다; 나머지는 알아서 채워집니다.
3. **요약 생성**을 실행하세요. 공유한 내용이 공유 헤딩 아래에 나타나고, 요약은 요약 헤딩 아래에 표시되며, 공유된 노트들은 보관함으로 이동합니다.
4. 쓴 글에 대한 답변을 원할 때 **일기 피드백 생성**을 실행하세요.

또는 일정을 설정하여 3단계와 4단계가 알아서 실행되도록 할 수도 있습니다.

## 일일 노트 레이아웃

첫 번째와 세 번째 섹션은 당신이 작성하고, 두 번째와 네 번째 섹션은 AI가 작성합니다.

```markdown
## 저널
- 오늘 한 일

## AI 피드백
- (AI가 여기에 작성하며, 타임스탬프가 찍힙니다)

## 오늘의 공유
- (AI가 공유한 링크를 여기에 나열합니다)

## AI 정리
- (AI가 여기에 작성하며, 타임스탬프가 찍힙니다)
```

헤딩은 Obsidian의 언어 설정을 따르므로, 중국어 인터페이스에서는 `## 日誌`, `## AI回饋` 등과 같이 작성됩니다. 한 언어로 작성된 노트는 다른 언어에서도 계속 작동합니다: 매칭 시스템이 모든 로캘의 헤딩을 인식하며, 이미 존재하는 섹션은 새로 쓰이는 대신 기존 헤딩을 그대로 유지합니다.

섹션은 헤딩을 통해 찾아지므로, 파일 내의 순서는 중요하지 않습니다. 명령을 다시 실행하면 이전 내용을 바꾸는 대신 새로운 타임스탬프 블록이 추가되므로, 하루에 여러 번 실행해도 내용이 계속 쌓입니다. 이 네 가지 헤딩 밖에 있는 내용은 절대 건드리지 않습니다.

## 폴더 레이아웃

```
ai-companion/
  journal/              daily notes; each day may get a folder of its own for reports
  news/
    landing/            ← share to this folder from your phone
    archived/           processed shares are moved here
  memory/
    facts.md            what the AI knows about you — edit it freely
    _log.md             append-only record of when it was updated
```

모든 폴더는 설정에서 구성 가능합니다. 플러그인이 로드될 때 생성되므로, 모바일 공유 시트에서 찾으려고 할 때 이미 착륙 폴더가 존재합니다.

## 설치

데스크톱에 Obsidian 1.5.0 이상이 필요합니다.

1. 최신 릴리스에서 `main.js`, `manifest.json`, 그리고 `styles.css`를 다운로드하세요.
2. 이것들을 `<vault>/.obsidian/plugins/ai-companion/` 안에 넣으세요.
3. 설정 → 커뮤니티 플러그인에서 **AI Companion**을 활성화하세요.
4. 설정 → AI Companion에서 AI CLI PATH를 설정하세요.

### CLI 설정하기

이 플러그인은 당신의 prompt를 로컬 AI CLI의 stdin으로 파이프하여 전송하고 그 stdout을 읽습니다. 따라서 명령은 비대화형으로 실행되어야 합니다. Claude Code의 경우:

드롭다운에서 CLI를 선택하면 비대화형 플래그가 자동으로 적용됩니다. 실행 파일이 `PATH`에 없는 경우에만 경로를 설정하세요.

| CLI | 상태 |
| --- | --- |
| Claude Code | 검증됨; prompt가 stdin으로 전송됨 |
| Antigravity (`agy`) | 검증됨; prompt가 인자로 전달됨 |
| Codex (ChatGPT) | 제공되나 테스트되지 않음 — 결과를 보고해 주세요 |

명령이 아무런 출력도 보고하지 않는다면, CLI가 대화형 세션을 원했을 가능성이 높습니다; 추가 인자 아래의 플래그들을 확인하세요.

### 소스에서 빌드하기

```bash
npm install
npm run build
```

## 명령어

이 모든 명령어는 명령어 팔레트와 리본 아이콘 뒤의 메뉴에 있습니다.

| 명령어 | 기능 |
| --- | --- |
| 새 일기 노트 | 템플릿에서 오늘의 노트를 만들고 엽니다 |
| 일기 피드백 생성 | 각 부분에 필요한 목소리로 오늘의 일기에 답합니다 |
| 요약 생성 | 공유한 항목을 나열하고 각각에 대한 요약을 작성합니다 |
| 사실 누적 | 오늘의 일기에서 사실 테이블을 업데이트합니다 |
| 사실 테이블 열기 | 읽거나 수정하기 위해 `facts.md`를 엽니다 |
| 처리된 공유 보관 | 처리하고 남은 공유 항목들을 모두 정리합니다 |

일기 노트에 작성하는 명령어들은 비일기 노트가 열려 있는 동안에는 비활성화되므로, 실수로 바꾸고 싶지 않은 파일에서 실행되는 일이 없습니다.

## 설정

- **AI** — CLI(Claude Code, Antigravity, Codex)를 선택하면 필요한 플래그가 채워집니다; 또는 Custom을 선택할 수 있습니다. 추가로 경로, 추가 인자, 모델, 시간 초과를 설정할 수 있습니다.
- **Voices** — 상황 → 목소리 테이블 및 각 목소리의 지시사항. 모든 내장 항목은 개별적으로 초기화 가능하며, 자신만의 상황과 목소리를 추가할 수 있습니다.
- **Journal** — 폴더, 날짜 형식, 템플릿 경로 (`{{date}}` 및 `{{time}}` 지원). 사용자 정의 템플릿은 반드시 4개의 헤딩을 유지해야 합니다; 이 헤딩들이 AI가 쓸 곳을 찾는 방법이기 때문입니다.
- **News** — 착륙 및 보관함 폴더, 리서치 토글, 보관함 보존 기간(일 단위, 0은 모두 유지).
- **Schedule** — 수동(기본값), 열 때, 또는 N시간마다. 예약된 실행이 요약, 피드백, 또는 둘 다 실행할지에 대한 별도의 토글이 있습니다.
- **Facts** — 폴더, 그리고 활성화 토글(기본적으로 꺼짐).
- **Appearance** — 플러그인 자체 섹션에 대한 선택적 스타일(cards, quiet, magazine), 기본적으로 꺼져 있으며 일기 노트에만 국한됩니다. 스타일은 읽기 뷰에 적용됩니다; 모든 값은 Obsidian의 CSS 변수에서 가져오므로 여러분의 테마가 여전히 우선 적용됩니다.

### 예약 실행

예약된 실행은 Obsidian이 열려 있는 동안에만 일어납니다 — CLI 기반 플러그인에는 백그라운드 프로세스가 없으며, 놓친 시간은 한꺼번에 처리되지 않고 다음 주기에 실행됩니다.

요약 기능은 예약 실행에 적합합니다. 각 실행 시 도착한 새로운 공유 항목을 처리하기 때문입니다. 일기 피드백은 예약 실행에서 기본적으로 꺼져 있습니다: 실행할 때마다 새로운 블록이 추가되기 때문에 하루에 6번 실행하면 섹션이 거의 똑같은 조언으로 채워집니다.

## 개인정보 및 안전

기능을 켜기 전에 이것을 읽으세요.

- **당신의 일기는 AI 제공자에게 전송됩니다.** 플러그인은 로컬 AI CLI를 생성하고 당신의 일기 텍스트를 거기로 보냅니다. 그 CLI가 무엇을, 누구에게 전달하는지는 이 플러그인이 아니라 해당 도구에 의해 결정됩니다. 일기에는 건강 정보와 가족 문제 등의 상세한 내용이 포함됩니다; 신중하게 결정하세요.
- **AI는 당신의 vault에 직접 작성합니다.** 확인 단계가 없습니다. 위에서 나열한 섹션들만 작성하지만, 묻지 않고 바로 작성합니다.
- **출처가 보존됩니다.** `memory/_log.md`는 추가만 가능하며 각 사실 업데이트가 어느 날짜의 일기에서 왔는지 기록합니다. 따라서 당신이 작성한 것과 AI가 추론한 것을 분리할 수 있습니다.
- **사실 테이블은 당신이 편집할 수 있습니다.** AI가 뭔가 잘못 기록했다면 열어서 수정하세요; 다음 실행 시에는 당신이 수정한 버전을 읽습니다. AI가 매번 파일 전체를 다시 작성하므로, 당신의 일기에 뒷받침하는 내용이 없는 줄은 살아남지 못할 수 있다는 점에 유의하세요.
- **예약 실행의 기본값은 수동입니다.** 당신의 vault에 글을 쓰는 무인 실행은 기본값이 아닌 선택 사항이어야 합니다.
- **보관함 삭제는 선택 사항이며** 시스템 휴지통을 사용하므로 복구할 수 있습니다.
- **데스크톱 전용.** CLI를 생성하려면 Node가 필요하므로 모바일에서는 실행할 수 없습니다. 휴대폰에서 vault로 공유하는 것은 문제없이 작동합니다 — 그것은 그저 Obsidian Sync일 뿐입니다.

## 국제화

인터페이스는 Obsidian의 자체 언어 설정을 따라 21개 언어로 제공됩니다: 아랍어, 독일어, 영어, 스페인어, 페르시아어, 프랑스어, 인도네시아어, 이탈리아어, 일본어, 한국어, 네덜란드어, 폴란드어, 포르투갈어, 포르투갈어(브라질), 러시아어, 태국어, 터키어, 우크라이나어, 베트남어, 중국어(간체), 그리고 중국어(번체).

번역 파일은 `src/i18n/locales/`에 있습니다. 각 로캘은 영어 기준의 타입 검사를 받으므로, 누락된 키는 조용한 대체가 아닌 컴파일 오류를 일으킵니다.
